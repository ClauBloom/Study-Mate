# 题目唯一规范

**题目的唯一 owner 是 `practice-evaluator`**——题面、答案、要点、lab 实操题、`solutions/` 全由它出，其他角色不碰题目内容（`learning-coach` 只把题嵌进课件并决定位置与行文）。**数据字段**以 `templates/assets/quiz.js` 顶部注释为准（渲染器的契约），本规范不重复字段表——本规范管**出什么题、怎么要求、什么算过**。（同一件事的两个叫法：规范与字段契约里叫**算过标准**（`criteria`），页面上给学生看的文案叫「要点标准」。）

## 一、四层

默认进阶路径，不是必须逐级走的台阶：学生在项目里用过某知识点可以从高层起步，某层反复卡住可以退回来补。

| 层 | 类型 | 出题要求 | 通过标准 |
|----|------|---------|---------|
| L1 理解 | 判断/解释/预测输出 | 每题追问"为什么" | 能解释原因，不只给结论 |
| L2 改造 | 修改已有代码观察变化 | 给可运行的 10-20 行代码，指定一处改动 | 能预测改动结果并运行验证 |
| L3 排错 | 真实 bug 定位 | 给含 1-2 个 bug 的代码或真实报错 | 能说出根因 + 修复 + 预防 |
| L4 应用 | 放进真实项目 | 任务挂到项目上，交付物明确 | 代码跑通 + 测试通过 + 能解释取舍 |

**层级上限由课型定**：`kind: 概念` 止于 L3；`kind: 实操` 与 `kind: 实验` 可到 L4。**L1-L4 是"题"的词汇，不进页面**：它用来选出题深度、记进评估记录的 `layer` 字段；页面上的题只写题面、选项／参考答案、要点，不挂 L 标，也**不要用 L1-L4 标动手块或跟做步骤**（那些标题按内容写，如"第 3 步 · 改造"）。

## 二、四种题型

| 题型 | 长什么样 | 判分 | 适合的层 |
|------|---------|------|---------|
| **选择题** | 页内 `.quiz`，点选项即时反馈 + 一句 `why` | 页内自动判 | L1、部分 L2 |
| **开放题** | 页内出题，学生先自己想/写，**参考答案与要点标准点击展开**（不贴回会话） | 学生自评 | L1 追问为什么、L2 预测、L3 找根因 |
| **实操题** | `lab/` 的留白任务 + 断言 + `solutions/`，学生亲手写代码 | 载体自带的测试命令自动判（`npm test`／`make test`／`./run_tests.sh`…） | L2、L3、L4 |
| **评估题** | **阶段评估**时出的 1 题（最多 2 题，开放） | `practice-evaluator` 判 | 按目标层级 |

选题型：**能自动判的优先选择题；要"说清为什么／找根因／解释取舍"的用开放题；要真跑代码的用实操题。**

## 三、出题要求

- 贴近生产场景与真实报错，**坚决避免"背诵定义"的「教条主义」**
- 选择题选项尽量等长、同句式（长度泄露答案，闸门只 `WARN` 不阻断）
- **开放题必须同时给参考答案与标准**——学生据此自评，缺一不可；答案不唯一时参考答案要给出可接受的替代方案与判断依据
- 每题备好参考答案与常见错误答案，供批改对照
- 实操题写成可核验的（断言／期望输出／清单），`solutions/` 与任务分开放、做完才对照
- **题量按"学生作答总时长"估，目标 ≤10 分钟**（不设下限也不硬限题数）：实操课与实验课把题量让给动手，概念课可以多问几道；开放题的参考答案要克制，别写成小作文
- **评估题只问理解与权衡**：对比（"你觉得 X 相比 Y 有什么好处"）、因果（"为什么必须这么做"）、预测（"改了这一处会怎样"）、取舍（"什么场合不该用它"）、迁移（"你项目里哪一处能用上"）。**不问机械回忆**——文件名、命令原文、终端输出、报错的行号列号这类东西，要么由 `lab/` 的断言机器验，要么本就没有教学价值；"想不起来"不该成为判定依据
- 一次最多 2 题，**每题最多 3 个小问**；评估的总作答时间 ≤5 分钟（页内自测另算）
- **题面超过一行就自己排版**：题面是纯文本写进页面的，`\n` 会原样保留（渲染器对此有支持），**换行位置由作者定、不由容器宽度定**。枚举多个小问（①②③）时每项各自起一行；**多行代码一律写进 ` ``` ` 围栏**（起止各占一整行，中间照原样写——缩进与空格都保留，渲染成真代码块并自动上色；字段与写法见 `templates/assets/quiz.js` 顶部契约）。**行长分两类判**（排错题必然要贴代码，代码天生比散文宽）：

  | 这一行是什么 | 上限 |
  |---|---|
  | 纯散文行（题干、设问、说明） | ≤40 字 |
  | 围栏里的代码行 | ≤60 字（按显示宽度算；再长代码块就横向滚动了） |
  | 靠空格对齐的注释列 | **放进围栏**里照原样对齐；裸写的多行会被折叠，读不出对齐 |

  选项（`opts`）不换行；参考答案与要点标准同样适用本条
- 出题前先读节点的 `objective` 与 `验收点`、学生最近的 misconceptions、目标层级；出题后逐题说明它对的是哪条 `验收点`（**软对照**：不强制全覆盖，没覆盖的在评估记录里写明理由）

## 四、三种课型（`curriculum.yaml` 的 `kind`）

| `kind` | 是什么 | 产出 | 题目上限 |
|--------|--------|------|---------|
| **概念** | 普通课，只讲不落 lab | 课件（讲解 + 轻量跟做） | L3 |
| **实操** | 普通课，学一点练一点 | 课件 + **自己的小 lab**（当课练习） | L4 |
| **实验** | **里程碑验收课**：与普通课同级插在大纲里，验收"学到目前的知识能做出什么" | **实验说明页**（任务书）+ 实操任务（任务本身就是验收） | L4 |

实验课验收哪些课写在它的 `prerequisites` 里；进度与置位规则见 `record-keeping`。

## 五、要点标准

- 结论三档：`通过 / 部分通过（列出缺哪条）/ 不通过（列出原因）`，并给"差一步就能过"的具体建议
- **每条结论必须指向一条具体证据**（作答原文、运行结果、交付物）；指不出具体证据按"不通过"处理
- **不得因为"题是我出的"或"学生说懂了"就判过**——说懂了不是证据。证据可信度排序见 `evidence-check`

## 六、实操题（lab）规范

**载体由总控与学生确定**（盘问时确认；首个 `kind: 实操/实验` 的节点建 `lab/` 时落盘进 `lab/README.md`，在那之前由总控随派工 prompt 传——`record-keeping` 的"科目文件夹"管这个顺序）；本节只管载体定下来后怎么做。lab 全部内容由 `practice-evaluator` 产出、总控写盘；讲解角色不碰 lab。实验课用同一套要求，另加一份实验说明页（要做出什么、要点、自查清单、指向实操）。

不管什么载体，都要做到这五条：**分步引导**（一小步讲解 + 立刻动手，不一次抛完整任务）；**亲手做**（任务留白给学生写，成品只放 `lab/solutions/`，做完才对照）；**可验证**（能自动验的写断言，不能的给自查清单／期望输出）；**即时反馈**（做完立刻能验，不等 agent）；**卡壳先引导**（读错误信息 → 提示 → 线索，不给答案）。教程部分要带结果（其他语言先跑一遍或贴运行结果）；任务写清"要做什么、要点是什么"（`▸ 你的任务` 只是常见写法，不是必须）。

结构（编号与课件同源）：任务与断言放 `lab/NNNN-主题/`（或 `NNNN-主题.ipynb`）；答案放 `lab/solutions/NNNN-主题/`，与任务分开放、做完才对照；`lab/README.md` 写载体与环境依赖 + 任务表与卡壳顺序。

**参考解必须自包含**：学生把 `solutions/` 里的文件拷进自己的任务目录后要能直接编译、直接跑——参考解引用的模板、头文件、夹具都得在它自己那份里；要单独入库的模板（如 `myfastio.h`）另存一份进任务目录，并在 `README.md` 写明两者分工。本轮踩过：参考解 `#include "fastio.template.h"`，而那个头文件只在 `solutions/` 里——学生照 README 拷成 `fast.cpp` 后**必然 CE**。

## 七、题目位与切片对位

**题目位**是课件里预留一个题块的位置，讲解角色在正文留一行注释标记：`<!-- 题目位：L1 概念题 ×2 -->`、`<!-- 题目位：动手块（实操课，指向 lab/NNNN-…） -->`。**动手段落也算一个位**——真的不该出题就交空数组 `[]` 加一句 `empty_reason`，别把位悄悄去掉。每处放几道题按第三节的题量估；位的**数量不预设**、按内容定，但每一处都要有交代：没出题的位说清怎么处理（收紧到相邻题、或删掉那处注释）。

**切片编号必须与页面物理顺序一致**（第 N 片 = 从上往下第 N 处）。做不到一致（题型互换等）**必须在 manifest 里给「片 ↔ 位」映射表**，并且每一片都带一个**内容锚点**（该片首题首行的文字、或一个特征串）：序号对位在不一致时会**静默错位**，题本身都是好题、只是落错了小节，肉眼几乎看不出来。

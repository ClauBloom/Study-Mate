这一轮把课件的产出格式从**模型手写 HTML** 换成**内容文件（Markdown 子集 + `:::` 指令）+ 确定性渲染器**，
然后在真实科目上拿**下一个未学节点**真跑了一课。计划本体、约束与验收口径见
[课件生成提速实施计划-2026-09-20](课件生成提速实施计划-2026-09-20.md)；语法的唯一规格见
[课件内容格式](课件内容格式.md)。

> `wc -c` 与脚本统计，闸门/自检的结论取命令退出码。量法写在各表下面的注里，照着命令可以重跑。

## 一、撤掉了什么

| 撤掉的 | 现在谁做 |
|---|---|
| 模型手写 HTML 正文（标签、实体转义、共享层引用、上下节指针、文件名序号） | `scripts/render_lesson.py` —— **唯一的 HTML 产出者**。模型只写内容与题；页面由渲染器从内容文件 + 题库 + `curriculum.yaml` + 模板壳一次渲染 |
| 出题人交题之后**由讲解把题原样贴回正文**的那一跳（已取消） | 讲解在正文里留题目位 `::: quiz <层级> 锚点：<锚点文本>`，出题人按**同一串锚点**交 `quiz.json`，渲染器按锚点取题合入——题面与答案一个字不改 |

**为什么撤** —— 三条实测（47.1% 与闸门那两条写在计划 §Spec 里；362 行用 `wc -l` 在本仓复核；
44.6% 是同科目单课的现场统计）：

- **旧路径 47.1% 的产出是标记与转义**：7 份真实课件正文区合计，标签 64,203 + 实体 3,930 字符 vs 纯文本 76,422
  （计划 §Spec 的实测基线；本轮真跑的同一科目里，`0007-cpp.recursion.html` 单课 **44.6%**——标签 9,398 +
  实体 285 vs 纯文本 12,025）。也就是说模型每写 100 个字符，有近 47 个是在写 HTML 而不是在讲课。
- **闸门 9 项检查里 6 项是纯 HTML/接线不变量**（头部与共享层引用、主题开关、上下节指针、文件名序号、
  题目块属性转义……）。这些不变量既不该由模型负责，也不该由模型来 debug。
- **一次会话踩出的 HTML/转义陷阱，交接文档 362 行**（`docs/引擎修复交接-2026-09-18.md`，`wc -l` = **362**）。
  另一件事同样说明成本：`scripts/tests/test_quiz_attr.py`（9 例）与闸门里 3 条检查，只为
  「题目块属性值三层转义」这一件事。

撤完之后模型产出里还剩什么标签：**只剩 `::: svg` 块里的内联示意图**（那是模型画的图，内容本身）与
**代码围栏里的原文**（那是代码本身）——两处都按原样透传，不算标记开销。

## 二、现在怎么跑（串行两段）

```text
learning-coach（第一段）     正文 + 题目位锚点 → lessons/<序号>-<节点id>.md，并交回锚点清单
practice-evaluator（第二段） 按逐字锚点逐个交代：交题，或交一行 empty_reason → quiz.json；
                             实操/实验课另交整套 lab（任务 + 参考解 + 判分脚本 + README）
总控                         cp 题库与 lab 落盘 → render_lesson.py → check_lesson.py --subject --node → present
```

两段是**串行**的（R14）：锚点是讲解现场发明的产物（它决定题放哪、上下文是什么），出题人拿到的必须是
**逐字**的锚点清单，所以出题人在讲解交付之后才派出。

**三个文件各归谁**（与 `docs/使用说明.md` §三同一口径）：

| 文件 | 谁写 | 怎么改 |
|---|---|---|
| `lessons/<序号>-<节点id>.md` | 讲解角色的**内容**：正文、配图、题目位 | **改课件改它**，改完重跑渲染器 |
| `lessons/<序号>-<节点id>.quiz.json` | 出题角色的**题**：`{"锚点文本": [题, …]}`，键与内容里的锚点逐字对应 | **改题改它**，改完重跑渲染器 |
| `lessons/<序号>-<节点id>.html` | **渲染器产物**，学生看的页面 | **不要手改**——下次渲染就冲掉，两份源文件也会跟它脱节 |

**命令**：

```bash
python3 scripts/render_lesson.py <科目目录> <节点id>            # 内容 + 题库 → 课件 HTML
python3 scripts/render_lesson.py <科目目录> <节点id> --check    # 讲解角色自检：只解析校验、不写盘
python3 scripts/check_lesson.py <页面> --subject <科目目录> --node <节点id>   # 质量闸门
```

- 渲染器**只产出** `lessons/<序号>-<节点id>.html` 这一个位置（`scripts/render_lesson.py` 里落盘的
  `out_path` 就这一处）；`--check` 走同一套解析与渲染，最后一步不落盘（成功打印 `OK …（只校验，没有写盘）`）。
- 认不出的语法/指令、锚点无题又没有 `empty_reason`、引用的图不存在 —— 一律 `<文件>:<行> <问题>`
  报错并非零退出，**绝不静默降级**。
- **`kind: 实验` 的说明页走同一条路**（R12）：内容由出题角色交、总控原样写进 `.md`，渲染器出 `.html`。
  它是任务书、**不出题**，所以不写 `:::` quiz 题目位、也没有 `.quiz.json`，只有 `.md` + `.html` 两件。

### 3.4 讲解自检、出题交付与 lab 交付态

  `empty_reason`、也没有删题目位，正是提示词里写的「题库/锚点类报错此时是预期的，其余改到没有」。

## 四、观察项：闸门的 WARN 噪声（不是缺陷）

首轮闸门虽然 `OK`，但 WARN 里绝大多数是「题目字段里出现 Markdown/HTML 标记」的提示，触发词是
**代码片段**：`-O0`、`a[2] = 0`、`i < n`、`const int MAXN = 100005;`、`ulimit -s`；另有几条
「选项长度差 > 4」（实测 **5 / 6 / 7**）。

题目字段是**纯文本**（换行用 `\n`、代码写进围栏），里面出现代码片段是正常内容；这些是
`check_lesson.py` **既有**的启发式提示项，**不阻断**。本轮把它记成**观察项**——启发式偏噪，
值得单独一轮收窄——**不当缺陷处理**。

唯一的结构性 WARN 是「下节课 `0009-exp.first-blood.html` 还没产出——悬空指针，属正常」：
新课刚产出、下一课还没做时的正常态。

## 七、可迁移性与复现

- 本机相关的东西**没有进引擎**：渲染器的输入全是科目目录里的相对路径（内容文件、`quiz.json`、
  `curriculum.yaml`、`subject.yaml`、模板壳），依赖是**标准库 + pyyaml**——与 `check_lesson.py` /
  `gen_home.py` **同口径**，不引第三方新依赖；零网络、不调外部工具。
  两条可迁移 grep 在 `.dsh/skills/ templates/ scripts/` 上**无输出**（退出码 1）：绝对路径
  `/home/`、`C:\` 为空；禁用词 `matplotlib|figure-designer|PITFALLS|cjk_line|cjk_bar|--figures` 为空。
  （跑之前清掉 `scripts/tests/__pycache__`：Python 编译产物里会嵌源文件的绝对路径，那是它的性质，
  不是源码里真有本机路径。）
- **复现这一课**：在任意**临时科目目录**里摆好真实大纲与共享层，写一份 `lessons/0008-cpp.array.md`
  与配套 `.quiz.json`，跑第二节那三条命令即可；`kind: 实操` 的节点闸门还会要求 lab 产物齐全。
  本轮的两份模型产物按口径不入库（git-ignored 现场留档），要照着看就在临时科目里重跑。

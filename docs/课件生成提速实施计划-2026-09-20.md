# 课件生成提速实施计划（让模型写内容，不再写 HTML）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（一份任务一个实现者 + 逐任务评审）或 superpowers:executing-plans。步骤用 `- [ ]` 勾选跟踪。

**Goal:** 把"课件正文"的产出格式从 **HTML** 换成 **内容文件（Markdown 子集 + `:::` 指令）+ 确定性渲染器**：模型只写教学内容，HTML 由 `scripts/render_lesson.py` 从 `templates/lesson.html`（壳，改成占位符模板）+ `curriculum.yaml`（序号/前后指针/标题）+ 题目 JSON 一次渲染出来。

**Architecture:** 三个文件各一个 owner——`lessons/<序号>-<节点id>.md`（讲解角色：正文）、`lessons/<序号>-<节点id>.quiz.json`（出题角色：按锚点组织的题）、`lessons/<序号>-<节点id>.html`（渲染器产物，不再手写）。渲染器吃掉今天所有"HTML 不变量"类失败：头部/共享层引用/主题开关/上下节指针/文件名序号/题目块的 `data-quiz` 属性转义/代码块实体转义/`syo-editor` 行号对齐/图片存在性与题注来源。

**Tech Stack:** 纯 `python3` 标准库（解析器 + `html.escape`），不引第三方依赖；沿用 `gen_home.py` 既有的模板占位符约定 `<!-- @LEARN:NAME -->`。

**Spec（本计划的依据 = 实测 + 用户的判断）**
- **实测**：7 份真实课件正文区里，标签 64,203 + 实体 3,930 字符 vs 纯文本 76,422 → **47.1% 的产出是标记与转义**；闸门 9 项检查里 **6 项**是纯 HTML/接线不变量；`docs/引擎修复交接-2026-09-18.md` 362 行全是一次会话踩出的 HTML/转义陷阱；`test_quiz_attr.py`（9 例）+ 闸门 3 条专门检查只为"题目块属性值三层转义"一件事。
- **用户口径**：瓶颈不在编排，在"课件 agent 还要做 HTML、并在 HTML 上 debug"。渲染器方案经用户批准。
- **已实测的真实用法**（词汇表按它裁剪）：标签 `<code>`977、`<p>`390、`<td>`182、`<b>`177、`<pre>`132、`<span>`128、`<div>`108、`<h2>`69、`<tr>`64、`<li>`60、`<a>`44、`<sup>`43、`<th>`42、`<ul>`15、`<svg>`14、`<nav>`14、`<table>`12、`<sub>`8；类 `quiz`32、`lesson-practice*`26、`lesson-resources`21、`lesson-tip`8、`lesson-warn`5；动手块层级只有 `跟做`(24) 与 `实操`(2)；**`syo-editor` 用量为 0**（不实现）。

- **别碰**：`docs/实施计划.md`、`docs/设计方案.md`（历史文档）、用户未提交的 `docs/引擎修复交接-2026-09-18.md`。

  | 语法 | 渲染结果 |

  | `## 标题` / `### 标题` | `<h2>` / `<h3>`（h2 ≤14 字，闸门仍会 WARN） |

  | `- 项` / `1. 项`（2 空格缩进嵌套） | `<ul><li>` / `<ol><li>` |
  | ` ```lang ` 围栏 | `<pre data-lang="lang">` + **转义后的原文** `<code>`；缺语言 → 不写 `data-lang`（不上色） |
  | 管道表（第二行 `\|---\|`） | `<table><thead>…<tbody>…` |
  | `::: practice <层级> \| <标题>` | `<div class="lesson-practice">` + `__head` + `__level`/`__title` 两个 span |
  | `::: quiz <层级> 锚点：<文本>` | 由 `.quiz.json` 按**锚点**取题 → `<div class="quiz" data-quiz='…'></div>`；锚点无题时**必须**给 `empty_reason: <理由>`，否则报错 |
  | `::: figure <相对路径>` + `alt:` / `caption:` | `<figure class="lesson-figure"><img src alt><figcaption>`；图在池子里时代渲染器自动补「（来源：…，许可：…）」（读 `pool.md`）；文件不存在 → 报错 |
  | `::: svg` + 可选 `alt:` / `caption:` | `<figure class="lesson-figure lesson-figure--inline">` + 块内 SVG **原样透传** |
  | `::: tip` / `::: warn` | `<div class="lesson-tip">` / `<div class="lesson-warn">` |
  | `::: resources` / `::: related` | `<div class="lesson-resources">` / `<div class="lesson-related">` |
  | 其他 `:::` | **报错**（带行号） |

  渲染器自己产出、模型不写的部分：head 与共享层引用（`../../../assets/sayo/sayo.css`、`learn-theme.css`、`../assets/style.css`、`learn-theme.js`+`LearnTheme.apply()`）、顶栏与主题开关（`id="lesson-theme-checkbox"`）、`.lesson-header`（eyebrow = `<序号> · <title>`）、`.lesson-ask`、`.lesson-nav`（**前后指针按 `curriculum.yaml` 的 `nodes:` 顺序算**，第一课无 `--prev`、最后一课无 `--next`）、`.lesson-footer`、三个 `<script>` 与 `LearnTheme.wire(...)`。

## 验收判据

1. **标记开销消失**：新课内容文件里 `<`/`&` 只出现在代码围栏原文与 `::: svg` 块内（脚本统计）；HTML 全部由渲染器产出。
2. **一条链路一个可执行件**：`render_lesson.py` 是唯一的 HTML 产出者；`--check` 可只校验不写盘。

5. **旧产物不受影响**：7 份手写课件零改动且仍过闸门。
6. **实测数字**（Task 4）：派工次数、首轮闸门通过率、内容 vs HTML 体积、标记占比——写进实施记录。

**风险与止损**
- **表达力收窄**（最大风险）：块词汇表按实测裁剪（`syo-editor` 零用量故不实现）；需要新组件时按"渲染器加指令 + 测试"有意扩展。回退：提示词与模板是文本，恢复手写 HTML 路径即可；已交付课件从未被改写。
- **Markdown 子集的坑**（表格里的 `|`、列表里嵌代码块）：渲染器严格模式——认不出就带行号报错，绝不静默降级；golden 测试 + 闸门兜底。
- **渲染器 bug 影响所有新课**：golden 测试 + 闸门；渲染确定性、可随时重渲。
- **模板壳化的过渡窗口**：Task 1 之后、Task 2 之前，`learning-coach` 的提示词还写着"从 `templates/lesson.html` 拷起"，而模板已是占位符壳——同一分支上连续两个任务内解决，合并前不会带出去（评审看的是整支）。
- **不做**：预取下一节点、机械活降档（用户已确认开启，但排在渲染器之后，收益更清楚）；`reference/` 速查页仍手写 HTML（渲染器的下一个消费者）——实验说明页已并入渲染器路径（见 Task 2 的 R12）。

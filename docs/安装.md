# 安装

需要 DSH 0.1.5-rc.2 及以上、Node.js 22.19+（22 系列）或 24+、Python 3.9+ 和 PyYAML。

## 用安装器安装（推荐）

```sh
npx @yunmiao/studymate@latest install
dsh web
```

启动后新建会话，选择「学习模式」。更新时再运行同一条安装命令，然后重启 DSH。

默认学习工作区是 `~/StudyMate`，已有配置会沿用。可用 `--workspace <目录>` 指定其他目录。配置保存在 `~/.dsh/studymate-config.yaml`，更新会保留学习数据。

安装器按 DSH 版本选择预设格式，不会升级 DSH：

| DSH 版本 | 预设注册位置 | 工作流插件 |
| --- | --- | --- |
| 0.1.5-rc.2 至 0.1.6-alpha.1 之前 | `.agent-presets/learning` | `workflow-worker-thread` |
| 0.1.6-alpha.1 至 0.1.7-alpha.1 之前 | `.agent-presets/learning` | `workflow-ptc` |
| 0.1.7-alpha.1 起 | `profiles/web/cordis.patch.yml` | `workflow-ptc` |

表中路径都在 `DSH_HOME` 下，默认是 `~/.dsh`。升级或降级 DSH 后，重新运行安装命令即可适配。降级时，新版预设声明会被跳过，不会因缺少新版预设插件而阻断 DSH 启动；学习模式需要重新安装才能恢复。

默认供 `dsh web` 使用。其他 profile 可指定，例如：

```sh
npx @yunmiao/studymate@latest install --profile headless
```

源码安装同样支持 `./install.sh --profile headless`，Windows 使用 `./install.ps1 -Profile headless`。自定义 profile 需要先用 DSH 创建。

## 用 DSH 原生命令安装

适用于 DSH 0.1.7-alpha.1 及以上。还需要终端能运行 `pnpm`；启动时也需要 Python 3.9+ 和 PyYAML。

```sh
dsh plugin --profile web add @yunmiao/studymate
dsh web
```

首次启动会初始化学习工作区，默认是 `~/StudyMate`，已有配置会沿用。可在启动前设置 `LEARN_WORKSPACE` 指定目录。插件不需要本地构建。

更新后重启 DSH，并新建会话：

```sh
dsh plugin --profile web update @yunmiao/studymate@latest
dsh web
```

如果误装到旧版 DSH，原生入口会提示不兼容并跳过，普通模式仍可使用。此时请改用上面的 `npx` 安装命令。缺少 Python 或 PyYAML 时，按终端提示补齐依赖后再启动。

## 切换安装方式

已经用 `npx` 或源码安装过，再添加原生插件不会自动迁移，也不会改写现有预设。学习模式仍由原安装方式管理；例如，用 `npx` 安装的内容仍需用 `npx` 更新，单独运行 `dsh plugin update` 不会更新这部分内容。

要切换为原生安装，先停止 DSH，再依次运行：

```sh
dsh plugin --profile web add @yunmiao/studymate
npx @yunmiao/studymate@latest install --mode native
dsh web
```

切换需要 DSH 0.1.7-alpha.1 及以上，并已在该 profile 添加原生插件。安装器沿用学习工作区，移除自己写入的预设注册；之后用 `dsh plugin update` 更新。手工添加的同名预设或停用配置不会被覆盖，有冲突时会提示处理。

要切回安装器管理，停止 DSH 后重新运行默认的 `npx @yunmiao/studymate@latest install`，再启动 DSH。它会保留学习工作区，并停用同一 profile 的原生入口，避免重复注册。

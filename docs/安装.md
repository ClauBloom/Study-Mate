# 安装

需要 Node.js 22.19+（22 系列）或 24+、Python 3.9+ 和 PyYAML。

## 用 DSH 安装

适用于 DSH 0.1.7-alpha.1 及后续版本。请确认 `dsh`、`pnpm` 和 Python 可以在终端中运行。

```sh
dsh plugin --profile web add @yunmiao/studymate
dsh web
```

启动后新建会话，选择「学习模式」。插件不需要本地构建。

更新：

```sh
dsh plugin --profile web update @yunmiao/studymate@latest
```

更新已加载的插件时，可能需要重启 DSH。重启后请新建会话使用更新后的预设。

首次启动会初始化学习工作区，默认是 `~/StudyMate`，已有配置会沿用。可在启动前设置 `LEARN_WORKSPACE` 指定目录。配置和学习数据保存在 npm 包目录之外，更新插件会保留它们。

如果之前用 `npx` 或源码安装过，插件会清理安装器标记的旧预设注册，并提示重启一次。手工添加的同名预设不会被覆盖，需要按提示处理，避免重复注册。

## 用安装器安装

DSH 0.1.5-rc.2 起可使用以下方式，新版也继续支持：

```sh
npx @yunmiao/studymate@latest install
```

默认学习工作区是 `~/StudyMate`。用 `--workspace <目录>` 更换；重复安装会沿用已有配置。

安装器根据 DSH 版本选择预设格式：

| DSH 版本 | 注册位置 | 工作流插件 |
| --- | --- | --- |
| 0.1.5-rc.2 起 | `.agent-presets/learning` | `workflow-worker-thread` |
| 0.1.6-alpha.1 起 | `.agent-presets/learning` | `workflow-ptc` |
| 0.1.7-alpha.1 起 | `profiles/web/cordis.patch.yml` | `workflow-ptc` |

以上路径都在 `DSH_HOME` 下，默认是 `~/.dsh`。新版会把预设内容注册到 profile，预设文件也保留在 `.agent-presets/learning`。其他插件配置会保留。

如果已经通过 `dsh plugin` 启用 StudyMate，安装器会沿用插件注册，不会重复添加学习模式。

默认供 `dsh web` 使用。其他 profile 可指定，例如：

```sh
npx @yunmiao/studymate@latest install --profile headless
```

源码安装同样支持 `./install.sh --profile headless`，Windows 使用 `./install.ps1 -Profile headless`。自定义 profile 需要先用 DSH 创建。

安装完成后重启 DSH，新建会话并选择「学习模式」。安装器不会升级 DSH。如果以前手工在全局 `cordis.patch.yml` 声明过同名预设，安装器会提示处理该声明，以免重复加载。

## 一、待修：会造成学生可见故障的

### 1. `templates/assets/quiz.js` 契约缺「属性引号转义」规则

**现象**：`data-quiz` 写在单引号属性里，题面一旦含裸 `'`，浏览器就在那里截断属性，题目块退化成「题目数据解析失败」。真实报错文本里单引号极常见（`expected ';' before 'return'`、`it's`）。

**已核实的缺口**：`templates/assets/quiz.js` 顶部那段契约里，「转义」「引号」「实体」三个关键词的出现次数是 **0**——它完整写了字段表，却一个字没提属性值的引号怎么处理。

**已确证的证据**（headless Chrome 对照实验，本轮跑的）：

| 写法 | 浏览器 dump 出来的属性 |
|---|---|
| `data-quiz='[{"q":"a &#39;answer&#39; b"}]'` | `data-quiz="[{&quot;q&quot;:&quot;a 'answer' b&quot;}]"` ✓ 完整 |
| `data-quiz='[{"q":"a 'answer' b"}]'` | `data-quiz="[{&quot;q&quot;:&quot;a " answer'="" b"}]'=""` ✗ 截断 |

**修法**：在 `quiz.js` 顶部契约里补一条——值里的 `'` 写 `&#39;`、`"` 写 `&quot;`、`<` / `>` 写 `&lt;` / `&gt;`；并说明「属性值里出现**同种**引号是 HTML5 禁止的，浏览器必然截断」。

**注意**：`scripts/check_lesson.py` 已加 `check_quiz_attr_delimiters()` 在闸门拦这类写法（见第二节），契约补齐后两边口径要对齐——**契约负责告诉作者怎么写，闸门负责在写错时拦住**。

### 2. `templates/lesson.html` 页头「所属节点」没给格式要求，链路三处不一致

**现象**：课件挂不上科目主页的路线图（`gen_home.py` 出 WARN 后跳过）。本轮跑了 6 次主页生成才撞见这个 WARN。

**三处各说各话**：

| 位置 | 现在是什么 |
|---|---|
| `templates/lesson.html:59` | `<span class="lesson-header__eyebrow"><!-- 编号 · 所属节点 --></span>`——**注释占位，没说要填 id 还是标题、什么格式** |
| `scripts/gen_home.py:660` | docstring 声称「写 id 或写标题都认」，但原代码只在标题被 `所属节点：` 前缀包住时才认（**虚标能力**，本轮已补强，见第二节） |
| `scripts/check_lesson.py` | **完全不校验**这条 |

**为什么对中文科目是必踩**：节点 id 是 `hello.first` / `cpp.types` 这类拉丁名，而课件正文全中文、标题是「第一份能提交的代码」——`gen_home.py` 那条「兜底扫描全文找节点 id」永远命中不了。讲解角色按注释自然写成 `0001 · 第一份能提交的代码`（无 `所属节点：` 前缀），就挂不上。

**2026-09-18 追加的具体反例（同一天产出的 4 份课件实测）**：4 份的页头都写成「编号 · 节点标题」，**全部靠 eyebrow 的标题包含匹配才挂上**。其中 `0004-cpp.float.html` 的 `<h1>` 是讲解角色**自拟**的「0.9999999999 为什么判 WA」（不是节点标题）——它连 `<h1>` 兜底都用不上，**完全依赖页头那一行**。所以：

- 页头那行只要不含节点标题原字（比如写成「浮点为什么判错」），这份课件就**静默挂不上路线图**；
- 而讲解角色按 `lesson-design` 有充分自由自拟标题（它确实这么做了），**撞上的概率不低**；
- 这正是上面那条「`check_lesson.py` 必须加归属校验」的实证：现在只有总控跑 `gen_home.py` 时才会看到一条 WARN。

**修法建议**（三选一，推荐 A）：

- **A. 页头写成有格式要求的渲染字段**：模板里直接给可抄的样例，如 `<span class="lesson-header__eyebrow">0001 · hello.first · 第一份能提交的代码</span>`（把节点 id 显式写进页头），并在模板文件头的硬规则里说明「节点 id 必须出现在页头」。这样 `gen_home.py` 的 id 匹配走第一条分支，稳。
- B. 保留 `所属节点：` 前缀方案，但在模板里给出完整样例，并在 `check_lesson.py` 加一条「页头必须能解析出所属节点」的检查项（现在是沉默失败，只在主页生成时 WARN）。
- C. 改 `gen_home.py` 的兜底：文件名里的节点 id 直接当归属（`0001-hello.first.html` → `hello.first`）——**最省事且零歧义**，因为文件名本来就是硬规则且已被闸门校验。

> 无论选哪个，`check_lesson.py` 都该加一条校验：**课件必须能归属到一个真实存在的节点**。现在的沉默失败代价是「课件做了，主页上看不到」。

## 二、已修（代码侧）——别重复修，也别改冲突

以下 4 处本轮已改 **`<root>` 代码**并验证；与之相关的**文档描述**仍需第 1、2 条那类补写。

### 2.1 `scripts/check_lesson.py` · 文件名正则不认点号（已修）

```python
# 旧
LESSON_NAME_RE = re.compile(r'^(\d{4})-[a-z0-9]+(-[a-z0-9]+)*\.html$')
# 新
LESSON_NAME_RE = re.compile(r'^(\d{4})-(?:[a-z0-9]+[.-])*[a-z0-9]+\.html$')
```

**为什么必须修**：节点 id 允许点号（`hello.first`、`exp.first-blood`、`cpp.stl`），文件名沿用同一 id。旧正则下**本科目每一份课件都会永久 FAIL**，并连锁废掉检查项 8。
**验证**：随机 20 万条字符串，旧正则的匹配集是新正则的**真子集**（零回归）；8 个合法名全过、8 个非法名全拒。

### 2.2 `scripts/check_lesson.py` · 新增裸引号拦截（已修）

新增 `json_string_spans()` / `bare_delimiter_in_json_strings()` / `data_quiz_delimiter_span()` / `check_quiz_attr_delimiters()`，并接入 `check_quiz()`（带去重）。

**为什么必须修**：`DATA_QUIZ_ATTR_RE` 是贪婪匹配，比浏览器**宽松**——它能跨过裸引号取出「完整」的值，于是 JSON 解析通过、闸门报 OK，而学生的浏览器里题目块炸掉。
**判定原则**（避免误报）：只认「裸定界引号出现在 **JSON 字符串字面量内部**」这一种坏；出现在字符串之外（如属性尾部空白）不报。
**验证**：3 个坏写法全部拦下、5 个好写法零误报；把真实课件复制一份注入裸 `'` 后**恰好报 1 次**，原课件 0 次；真实课件闸门仍 `OK`。

### 2.3 `scripts/check_lesson.py` · `QuizScanner` docstring 原文错误（已改描述）

旧文写「HTML5 只禁止属性值里出现**同种**引号，裸 `'` 在单引号属性里合法，浏览器也照常渲染」——前半句恰恰说明裸 `'` 在同种引号属性里**正是被禁止的**，后半句自相矛盾。已改成正确表述并指向新的拦截检查。

### 2.4 `scripts/gen_home.py` · `lesson_node_id` 认不出页头标题（已补强）

原实现只在「标题被包在 `所属节点：` 里」时才认标题；现在按 **eyebrow → `<h1>` → `<title>`** 依次看，且**标题精确相等优先、包含匹配兜底**（防止「排序与去重」被「排序与查找的 STL 写法」这类更长标题抢走）。
**效果**：本轮课件的页头 `0001 · 第一份能提交的代码` 现在能正确归属到 `hello.first`，WARN 消失、课件挂上路线图。
**注意**：这是兜底补强，**第 2 条的模板/校验问题依然存在**——别的科目换个标题写法仍可能挂不上。

### 2.5 `templates/assets/sayo/sayo.css` · 代码块行号槽错位（已修）

`.syo-editor-gutter` 用 `font-size: 0.8125rem`、代码体 `0.875rem`，行高同为倍数 `1.75` → 每行高差 **1.75px**，9 行累计 **14px**。
**修法**：gutter `font-size: inherit`（行高锚回 body 字号），行号缩小交给 `.syo-editor-gutter span { font-size: 0.8125rem; }`。
**已同步**：`workspace/.learning/assets/sayo/sayo.css`（共享层副本）。

## 六、附：本轮已确认「无需修改」的结论

避免接手会话重复排查：

- **`check_lesson.py` 的文件名正则与 `NUMBERED_NAME_RE` 分工是对的**：前者严格（课件必须合规），后者宽松（核对同目录其他编号文件），不用统一。
- **`QUIZ_TAG_RE` 用 `[^>]*` 截标签是对的**：属性值里的裸 `>` 是无效写法，不会误截断。**只补 `data-quiz` 值的引号检查即可**，别把它也改成非贪婪（那会把原有的取值逻辑改坏）。
- **闸门的「悬空指针 WARN（下节课未产出）」不是问题**：逐课推进时必然出现。
- **共享层 `sayo.css` 的 `.syo-editor` 结构本身没问题**，只有行号槽字号那一处（已修）。

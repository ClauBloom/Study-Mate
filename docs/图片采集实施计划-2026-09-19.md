## Global Constraints

- **不生成图**：不出现 matplotlib / venv / 绘图脚本 / 字体探测 / 数据图模板；`grep -rn 'matplotlib\|figure-designer\|PITFALLS\|cjk_line\|cjk_bar' .dsh/skills/ templates/ scripts/` 必须为空（迁移期内允许出现在本文档与备份分支）。

- **只抓网页**：只抓 `RESOURCES.md` 里列出的链接（**R20 修正**：照字面只抓列出的链接会产出**恒空池子**，边界已改为「**清单点名的站点**是边界——从列出的 URL 起可沿同站链接**下钻一跳**、每个入口页最多挑 3 个同站正文页」；见 [图片采集实施记录-2026-09-19](图片采集实施记录-2026-09-19.md) §六）；**不抓 PDF、不抓动态加载内容、不漫游搜索**；同站低频串行（≤1 请求/秒）、尊重 robots。
- **命名可检索（硬）**：`<主题>-<子主题>-<要点>-<来源缩写>-<NN>.<ext>`；只用 `[0-9A-Za-z\u4e00-\u9fa5-]`、无空格、总长 ≤60；主题词必须与科目 `GLOSSARY.md` 的术语一致。**可机器校验**（Task 4 的 `check_pool.py`）。

- **角色约定**：新角色 frontmatter 带 `disable-model-invocation: true` + `user-invocable: false`；技能名 = 目录名；正文四段齐全（输入 / 怎么做 / 交付格式 / 边界）。

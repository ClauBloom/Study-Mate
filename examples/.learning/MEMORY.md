# 学习者记忆

## 我是谁

- 现有技能：JavaScript 熟练；后端与数据库零基础；线性代数只记得矩阵乘法
- 各领域当前水平：前端能写小页面；没做过完整项目

## 教学偏好

- 有效的讲法：先看能跑的例子，再看概念；一次讲一个点
- 容易烦躁的：大段定义、连续追问、被要求背术语
- 例子偏好：生活类比 + 代码片段；纯数学符号需要配几何图

## 学习习惯

- 可投入时间：工作日晚上 1 小时，周末 3 小时
- 节奏：一次 40-60 分钟为限
- 常见卡点：概念听懂但写不出来；看到报错先慌

## 跨科目观察

- 两类科目里都表现出"先动手再理解"的倾向
- 先讲清"为什么需要它"，后续吸收速度明显变快

# Mission: 线性代数

## Why

机器学习教材和论文里大段的公式，现在只能跳过——变量名认得，符号之间的关系读不出来。这门课要把那些
符号读成具体的东西：一组向量怎么拼出目标向量、一个矩阵把空间变成了什么样、一个方程组到底有几个解。
目标不是会算，而是拿到一段公式能说出它在做什么。

## Success looks like

- 拿到一个线性方程组，能说清它的解是唯一的、无解的还是有自由变量的，并手写消元把解写出来
- 看到 `Ax = b` 能说出「用 A 的列向量去拼 b」，看到 `A` 能说出它把哪些方向压扁了、哪些方向没动
- 能用 Python 标准库实现一遍消元与解的结构判定，并用手算结果核对程序输出
- 读完一篇讲特征分解的应用材料，能说出这一步在真实过程里对应什么（人口怎么迁移、图像怎么压缩）

## Constraints

- 数学底子：微积分学过、能用；线性代数零基础，只会解二元一次方程组
- 编程底子：Python 能写小脚本（读写文件、跑循环、装包）；C 语言上过一学期，指针生疏
- 时间：每周 3~4 次、每次 40 分钟，一个知识点一节课
- 偏好：先看「这解决什么问题」，再用具体数字走一遍，最后才给定义和符号；公式堆在前面会卡住
- 卡点预警：抽象符号（矩阵、下标）容易卡；看不见的过程需要先具体化再抽象

## Out of scope

- 数值线性代数（大规模稀疏矩阵、迭代解法、条件数与稳定性分析）——先把几何直觉与手算练熟
- 抽象代数与泛函分析（向量空间公理化、线性泛函、无穷维空间）——本课不碰
- 矩阵微积分与张量运算（自动求导、反向传播的推导）——留到需要时再补
- 用 numpy 或其它第三方库代劳——这门课的解方程代码只用 Python 标准库，写完再对照现成库

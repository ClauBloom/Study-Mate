## 教程部分（已完成，跑一遍就能看见结果）

- `ip_to_int(text)`：把 `"192.168.1.70"` 转成 32 位整数。四段各占 8 位，第一段在最高位，
  所以每读一段就"乘 256 再加"。这一步把"点分十进制"还原成一个可以比较、可以移位的数。
- `int_to_ip(value)`：反过来，每次取最低 8 位拼回去。两个函数合起来证明"地址就是一个 32 位整数"。
- `mask_of(prefix)`：`26 → "255.255.255.192"`。做法是造出 26 个 1 再左移到高位一侧——掩码本来就是
  "前面全是 1、后面全是 0"，这句话用移位写出来只有一行。

| 3 | `split_subnet(cidr, new_prefix)` | 把一个网段按更长前缀等分，返回 `"网络地址/新前缀"` 列表 | 「任务 3」4 条断言（`/24 → 4 个 /26`、`/24 → 64 个 /30`、子网不重叠且落在原网段内、非法前缀） |

每个任务函数上方的文档串写清了边界与要抛的异常（`ValueError`），实现前先读一遍。
三条提示：

- 块大小（主机位的容量）是 `1 << (32 - prefix)`，网络地址一定是它的整数倍
- 网络地址 = 地址的主机位清零；广播地址 = 网络地址 + 块大小 - 1
- `/31` 与 `/32` 是边界：按本文件的约定，可用主机数记 0，`first` 与 `last` 都取网络地址

计算机网络 Glossary

这门课从一次网页请求出发，讲清数据怎么被分层封装、怎么逐跳转发到另一台机器，最后用抓包把整条路走一遍。用词以此文件为准，课件正文与配图都照这里的写法。

两节都算这门课的规范用词：课件正文与配图用词以本文件为准。开课时先把主题词写进「待掌握」，
学生真的会用之后挪进「已掌握」——挪动本身就是一条学习记录。

待掌握

IP 地址 (IP address):
网际层给每台机器（严格说是每个网络接口）编的 32 位编号，写成四段十进制数。它决定包从哪台机器到哪台机器，与"哪个程序在收发"无关。
Avoid: 网络地址（那是网段里主机位全 0 的那个地址）、网址（网址是给应用层看的域名）

子网掩码 (subnet mask):
与 IP 地址逐位对齐的 32 位数，值为 1 的位划出网络号、为 0 的位留主机号。把地址与掩码逐位做与运算，就得到它所属网段的网络地址。
Avoid: 掩码长度（规范说法是前缀长度，写法如 /24）

前缀长度 (prefix length):
网络号的位数，写在地址后面用斜线隔开，如 192.168.1.0/24。它是掩码的另一种写法，/24 等于 255.255.255.0。
Avoid: 掩码位数、子网号（子网号是网络地址那一段）

网段 (subnet):
网络号相同的一组 IP 地址。同一网段内的机器可以直接互发帧；不同网段的通信必须交给网关转。
Avoid: 子网段、IP 段（口语可用，正式写作用"网段"）

广播地址 (broadcast address):
一个网段里主机位全 1 的地址，发给它的帧会被同网段所有机器收下，不能分给某台主机使用。网段的最后一个地址。
Avoid: 广播 IP、组播地址（组播是另一类地址，只有订阅了的机器收）

默认网关 (default gateway):
路由表里"其他条目都匹配不上时"的出口，通常是本网段路由器的接口地址。目的地址不在本网段的包，都由它接手。
Avoid: 网关 IP、路由器地址（一台路由器可以有多个接口地址，网关指的是配置在这一侧的那个）

逐跳转发 (hop-by-hop forwarding):
路由器收到包后只决定"下一跳交给谁"，把帧头换成下一跳的地址再发出去，整条路由此一段一段拼出来。每一段叫一跳。
Avoid: 路由（路由是算出路径这件事，转发是按表把包送出去）

路由表 (routing table):
本机或路由器上"目的网段 → 下一跳"的对照表。查询时按最长前缀匹配：掩码最长的条目胜出。
Avoid: 转发表（交换机用的是 MAC 转发表，按地址学出来；路由表是路由器的说法）

端口 (port):
传输层给进程编的 16 位编号，与 IP 地址合起来标识"哪台机器上的哪个程序"。同一台机器上可以同时有很多个连接，靠它区分。
Avoid: 接口、插座（socket 是"地址 + 端口 + 协议"的组合，见实验课）

三次握手 (three-way handshake):
TCP 建立连接时双方交换 SYN、SYN-ACK、ACK 三个报文段，用来确认双方的收发能力并同步初始序号。握手完成后才传数据。
Avoid: 三次确认、建立连接（握手是建立连接的手段，不是它的同义词）

已掌握

协议 (protocol):
通信双方对"这一段字节怎么解释"的共同约定：字段顺序、取值含义、出错怎么办。双方照同一份约定写，才能互相读懂。
Avoid: 规则、标准（协议是具体到字段的约定，"标准"是文档层面的说法）

分层 (layering):
把一次通信的职责拆成若干层，每层只跟自己的上下邻居打交道，同层之间才互相读懂对方写的字段。
Avoid: 分层结构、OSI 七层（OSI 是其中一个七层的参考模型，不等于分层这个想法）

封装 (encapsulation):
上层交下来的整块数据被当作载荷，本层在它前面加上自己的首部再交给下一层。对方收到后反向逐层拆掉，叫解封装。
Avoid: 打包、包装（"封装"特指逐层加首部这件事）

首部与载荷 (header / payload):
首部是本层自己要读的信息（地址、长度、校验），载荷是上层交下来的全部内容，本层不解释它。
Avoid: 包头、数据部分（口语可用；正式写作用"首部"与"载荷"）

帧 (frame):
网络接口层的数据单元。以太网帧由目的 MAC、源 MAC、类型、载荷与末尾校验组成，最小 64 字节、最大 1518 字节（不含前导码）。
Avoid: 数据包、报文（包是网际层的说法，报文是应用层的说法）

MAC 地址 (MAC address):
网卡的 48 位硬件地址，写成六组十六进制数。它的有效范围只是一段链路，跨网段时每一跳都会换成下一跳网卡的地址。
Avoid: 物理地址、硬件地址（都对，本课统一写 MAC 地址）、IP 地址（那是网际层的编号）

交换机 (switch):
按帧的目的 MAC 地址把帧从对应端口发出去的设备。它自己学一张"MAC 地址 → 端口"的表，表里查不到就向所有端口泛洪，同一时刻多对端口可以同时通信。
Avoid: 集线器（集线器只会把信号复制给所有端口，不认地址）、路由器（路由器按 IP 转发，跨网段时才用）

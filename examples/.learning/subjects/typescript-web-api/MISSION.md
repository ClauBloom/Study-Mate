# Mission: TypeScript Web API

## Why

想独立做出能上线的东西，不再只会写前端页面。学会后端后，可以把脑子里攒了很久的应用想法真正做出来给别人用。

## Success looks like

- 独立完成一个可部署的全栈 Web API（TypeScript + Node.js + PostgreSQL）
- 部署上线后真实用户能注册、登录、用 CRUD 功能，数据不丢
- 代码有测试，改动后敢重构

## Constraints

- 工作日晚上 1 小时、周末 3 小时
- 没做过后端，需要从 HTTP 基础补起
- 不想学 Java/Spring，只用 TypeScript 栈

## Out of scope

- 前端框架（React/Vue）——已有基础，本课不碰
- 微服务、消息队列、K8s——等单服务跑通再说
